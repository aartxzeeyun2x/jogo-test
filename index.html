Pronto para jogar?

Use A/D ou as setas para correr, Espaço para pular e C para ativar sua carta secreta no segundo tempo. Colete 5 bolas e leve até o gol para avançar.

← → / A D correr ESPAÇO pular / confirmar shootout C carta secreta P pausar
⚽

Objetivo

Recolha 5 bolas e leve o personagem até o gol para marcar e avançar para a próxima etapa.

⏱

Formato Kings League

Dois tempos: 20 minutos no primeiro e 16 no segundo. No modo arcade, cada segundo real representa um minuto de jogo.

🃏

Carta secreta

No segundo tempo, pressione C para usar uma carta especial. Cada partida sorteia uma das sete cartas.

Regras adaptadas para o jogo

O primeiro tempo apresenta a entrada progressiva de jogadores e gols em dobro nos minutos finais. No segundo tempo, o dado define a formação reduzida e uma carta secreta fica disponível. Se o placar terminar empatado, acontece o shootout; se houver liderança, começa o Matchball.

Este é um jogo de plataforma 2D acadêmico inspirado nas regras fornecidas. As regras esportivas foram adaptadas para a jogabilidade.
